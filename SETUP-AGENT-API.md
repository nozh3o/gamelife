# Запись из Клода — настройка

Можно подключить One как «коннектор» в Клоде и прямо в переписке диктовать
траты, тренировки и приёмы пищи — они сами появятся в приложении при
следующей синхронизации. Всё работает через тот же проект Supabase, что и
обычная синхронизация — отдельный аккаунт не нужен.

Как и распознавание еды по фото, это разовая настройка на десять минут,
без установки чего-либо на компьютер.

---

## Шаг 1. Обновить SQL

1. В проекте Supabase открой **SQL Editor**.
2. В приложении: **Настройки → Синхронизация**, нажми **📋 Скопировать код**
   (тот же код, что и при первой настройке синхронизации — он безопасно
   выполняется повторно и добавляет то, чего раньше не было: таблицу личных
   токенов и функцию `gamelife_agent_add`).
3. Вставь в SQL Editor и нажми **Run**.

## Шаг 2. Создать функцию

1. В проекте Supabase: **Edge Functions → Deploy a new function → Via Editor**.
2. Имя функции — ровно `agent-mcp`.
3. Удали содержимое редактора и вставь весь код из файла
   [`supabase/functions/agent-mcp/index.ts`](supabase/functions/agent-mcp/index.ts).
4. **Важно:** перед деплоем выключи переключатель **Verify JWT** (обычно
   рядом с именем функции или в её настройках после создания). Без этого
   Supabase будет требовать обычный вход в аккаунт ещё до того, как код
   функции вообще запустится — а у Клода такого входа нет и не будет,
   у него только личный токен из шага 3.
5. Нажми **Deploy**.

## Шаг 3. Создать личную ссылку

1. В приложении: **Настройки → Синхронизация → Запись из Клода**.
2. Нажми **🔑 Создать личную ссылку** (название необязательно — просто
   чтобы отличать несколько ссылок между собой).
3. Ссылка вида `https://ТВОЙ-ПРОЕКТ.supabase.co/functions/v1/agent-mcp/gl_xxxxxxxx…`
   показывается **один раз** — сохрани её сейчас. Она работает как пароль:
   кто угодно с этой ссылкой сможет дописывать в твои данные, поэтому не
   отправляй её никому и не публикуй.

## Шаг 4. Подключить в Клоде

Точный путь в интерфейсе Клода может немного отличаться в зависимости от
приложения (сайт / телефон), но суть одна: в разделе **коннекторов** (обычно
он в настройках аккаунта, «Connectors» или «Подключения») есть возможность
добавить **свой, кастомный коннектор** по ссылке — вставь туда ссылку из
шага 3 целиком.

После подключения просто попроси в обычной переписке: «Клод, добавь трату
500 рублей на обед» или «запиши тренировку: жим лёжа 60 на 8, 65 на 6» —
Клод сам поймёт, что нужно вызвать нужный инструмент.

## Что можно диктовать

- **Траты и доходы** — сумма, категория, комментарий, дата (по умолчанию
  сегодня), можно уточнить счёт, если их несколько.
- **Тренировки** — название, упражнения с подходами (вес и повторы).
- **Приёмы пищи** — название блюда, калории и БЖУ (можно приблизительно —
  как и с фото, всегда можно поправить в самом приложении).

Записи не появляются в приложении мгновенно: они сначала попадают в общую
очередь в облаке, а приложение забирает их при следующей синхронизации —
обычно это происходит в течение минуты после открытия приложения или само,
если оно уже открыто.

---

## Если что-то не работает

| Что видишь | Что проверить |
|---|---|
| Клод не может подключиться / коннектор не отвечает | Проверь, что переключатель Verify JWT выключен для функции `agent-mcp` |
| «неверный или отозванный личный токен» | Ссылка отозвана в Настройках, или скопирована не полностью — создай новую |
| Записи не появляются в приложении | Открой приложение и подожди синхронизацию, или нажми «☁️ Синхронизировать сейчас» в Настройках |
| Клод пишет «сервер ответил 404» | Проверь функцию напрямую: SQL Editor → `select public.gamelife_agent_add('test','transaction','{}'::jsonb);` — если ошибка про `digest(...) does not exist`, обнови SQL заново (кнопка «SQL-код настройки» в Настройках) и выполни повторно |
| Хочешь отключить доступ | Настройки → Синхронизация → Запись из Клода → ✕ у нужной ссылки — отзывается мгновенно |

Логи вызовов — **Supabase → Edge Functions → agent-mcp → Logs**.

---

## Важное про этот механизм

Это первая часть приложения, открытая наружу — раньше всё общалось только
между самим приложением и Supabase. Личная ссылка — единственная защита:
она не отображается повторно, хранится на сервере только в виде хеша
(как пароль), и её можно отозвать в один клик в любой момент, если она
куда-то утекла. Заведи для Клода отдельную ссылку и не переиспользуй её
ни для чего другого.

Протокол, которым говорит Клод с коннекторами (MCP), — сравнительно новый,
и это первое такое подключение в этом проекте. Если при первом подключении
Клод пожалуется на формат ответа — напиши, разберёмся вместе: сама запись
данных (SQL-функция) от этого не зависит и переживёт любые правки в
Edge Function.
