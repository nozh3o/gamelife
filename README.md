# One

Личный трекер: задачи и привычки, цели, финансы, питание и дневник.
Никакого сервера и интернета — всё работает прямо в браузере, данные хранятся
локально на этом компьютере.

## Как запустить

**На компьютере:** открой файл **`index.html`** двойным кликом.

**На телефоне:** нужно выложить папку на https-адрес — см. раздел
«Как открыть на телефоне» ниже.

## Разделы приложения

### Три типа задач
- **🔁 Привычки** — жмёшь «+» сколько угодно раз за день или «−» за срыв. Просто счётчик:
  сколько сделал и сколько сорвался. Бывают только положительные, только отрицательные
  или обе кнопки сразу.
- **📅 Ежедневки** — отмечаются раз в день по выбранному расписанию (дни недели). Ведут
  стрик «сколько дней подряд». Пропустил в запланированный день — стрик сгорает.
- **✅ Задачи** — разовые дела со сроком и чек-листом. За просрочку не наказывают,
  только напоминают.

У всего есть **сложность** (тривиальная / лёгкая / средняя / сложная) — просто метка
для себя, приоритет. Плюс теги, заметки и поиск.

### Цели
Три вида: **числовые** (копить прогресс — «накопить 500 000 ₸»), **пошаговые**
(список этапов) и **простые** (сделано / нет). С дедлайном, прогресс-баром и
опциональной денежной наградой — при достижении она сама попадёт в Финансы.

### Финансы — как в приложениях-кошельках
- **Несколько счетов** — наличные, дебетовые и кредитные карты, накопительные счета. У каждого свой цвет, иконка и баланс, который можно поправить вручную (например, после сверки).
- **Кредитки** отдельно показывают доступный лимит и полосу использования — потратил, баланс ушёл в минус, ровно как в жизни.
- **Переводы** между своими счетами не считаются ни доходом, ни расходом — просто перекладывают деньги.
- **Лимиты трат** по категориям (или на все траты сразу) — прогресс-бар зелёный/жёлтый/красный по мере приближения и превышения.
- **Категории с иконками**, свои можно добавить прямо при создании операции.
- Графики доходов/расходов по месяцам и разбивка расходов по категориям с процентами.

### Аналитика
Финансы и питание за последнее время: доход/расход и накопления по месяцам, разбивка
расходов по категориям за всё время, калории за 14 дней, средние показатели и стрик
дней с записями в дневнике питания. Плюс график настроения по записям в журнале.

### Журнал
Запись дня: настроение, три победы дня и свободный текст. Ведёт стрик «дней подряд».

### Питание
Суточная норма КБЖУ считается по формуле Миффлина — Сан Жеора из пола, возраста, роста,
веса, активности и цели (похудение / поддержание / набор). Добавить еду можно пятью способами:

- **🔍 Найти по названию** — живая подсказка по мере ввода. Основной источник — встроенный
  офлайн-справочник (`js/food-db.js`, более 400 блюд на русском: каши, мясо, рыба, супы,
  овощи, фрукты, выпечка, фастфуд, национальная кухня СНГ и Средней Азии — бешбармак,
  манты, плов, хачапури, айран, кумыс, баурсаки, — корейские салаты, спортпитание,
  детское питание, алкоголь) — отвечает мгновенно, без интернета и без ключей.
  Личные «Мои блюда» подмешиваются туда же, а открытая база Open Food Facts дополняет
  список марочными продуктами, если есть сеть.
- **📦 Штрихкод** — точные цифры с упаковки из той же открытой базы. Надёжнее оценки
  по названию для магазинных продуктов, потому что берёт данные с этикетки.
- **📖 Мои блюда** — личный словарь, добавление в один тап с пересчётом по весу порции.
- **✏️ Вручную** — для домашней еды.
- **📷 По фото** — оценка блюда по снимку. Требует разовой настройки, см. `SETUP-FOOD-AI.md`.

Уложился в дневную норму калорий (±10%) — приложение это отметит. Любая оценка по
фото показывается в редактируемой форме: цифры нужно проверить, особенно вес порции.

## Как открыть на телефоне

Приложение сделано как PWA: ставится на домашний экран и работает без интернета.
Нужно только выложить папку куда-нибудь по адресу с **https** — из-за требований
браузеров установка и офлайн-режим работают лишь на https (и на localhost).

### Вариант 1 — GitHub Pages (рекомендую)

Бесплатно, постоянная ссылка, https. Один раз настроил — дальше просто открываешь
ссылку на телефоне.

1. Завести аккаунт на github.com и создать **публичный** репозиторий. На бесплатном
   тарифе Pages работает только с публичными — но это безопасно: в коде нет ничего
   личного, а весь твой прогресс хранится только в браузере телефона и никуда
   не выкладывается.
2. Загрузить в него содержимое этой папки (кнопка «Add file» → «Upload files»,
   перетащить всё, включая папки `js` и `icons`).
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
4. Через пару минут появится ссылка вида `https://ИМЯ.github.io/gamelife/`.
5. Открыть её на телефоне и установить на домашний экран (см. ниже).

### Вариант 2 — Netlify Drop

Без git и командной строки: зайти на app.netlify.com/drop и перетащить туда папку
`gamelife` целиком. Сразу выдаст https-ссылку.

### Вариант 3 — только дома, по Wi-Fi

Запустить `start-for-phone.cmd` на компьютере и открыть на телефоне показанный адрес
вида `http://192.168.x.x:8934`. Работает, пока компьютер включён и оба устройства
в одной сети. Установить на домашний экран и пользоваться офлайн так **не получится** —
для этого нужен https из вариантов 1–2.

### Установка на домашний экран

- **Android, Chrome:** меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
  Если приложение это предлагает, в Настройках появится кнопка «Установить как приложение».
- **iPhone, Safari:** кнопка «Поделиться» → «На экран «Домой»». Именно Safari —
  в Chrome на iPhone такого пункта нет.
- **Windows, Chrome или Edge:** значок с монитором и стрелкой справа в адресной
  строке → «Установить». Появится ярлык в меню «Пуск» и отдельное окно без
  адресной строки — то есть на компьютере это тоже полноценное приложение.

После установки One запускается как обычное приложение: своя иконка,
без адресной строки, работает без интернета.

## Синхронизация между устройствами

Работает сразу, без настройки: в **Настройках → Синхронизация** достаточно завести
аккаунт — просто почта и пароль. Никакого Supabase заводить не нужно — проект и
функция распознавания фото уже подключены по умолчанию (адрес и публичный ключ
зашиты в `js/sync.js`, это безопасно — они специально предназначены для клиентского
кода, а изоляцию данных обеспечивает RLS-политика в базе).

### Для друзей

Один и тот же адрес приложения годится для скольких угодно человек — каждый заводит
свой аккаунт и получает полностью свою, изолированную копию прогресса. Данные одного
пользователя физически не видны другому: это гарантирует политика Row Level Security
в базе (`auth.uid() = user_id`), а не «доверие» на уровне кода. Проверено вживую —
два тестовых аккаунта видят строго свои записи и не могут прочитать чужие, даже
намеренно запросив чужой `user_id` напрямую.

Разбор фото при этом расходует баланс сервиса распознавания у владельца проекта —
это сознательный выбор (см. `js/sync.js`, комментарий в начале файла). Если нужно
ограничить круг пользователей, самый простой способ — добавить проверку кода-приглашения
в Edge Function.

### Если нужен свой отдельный проект

В Настройках есть кнопка **«Использовать свой проект Supabase»** — открывает форму
для тех, кто хочет держать данные в собственном хранилище, а не в общем.

1. Зарегистрироваться на **supabase.com** (бесплатно, без карты) и создать проект.
2. В проекте открыть **SQL Editor**, вставить код из формы (кнопка «Скопировать код»)
   и нажать **Run** — создаст таблицу и то же самое правило доступа.
3. **Authentication → Sign In / Providers → Email** → выключить **Confirm email**.
4. **Project Settings → API → Legacy anon, service_role API keys** → скопировать
   **Project URL** и ключ **anon** в поля формы.
5. Завести аккаунт по почте и паролю.
6. Для распознавания фото — развернуть свою Edge Function, см. `SETUP-FOOD-AI.md`.

### Как это работает

- Изменения выгружаются через несколько секунд после того, как ты что-то сделал,
  и подтягиваются при открытии приложения и при возвращении в него.
- Без интернета всё работает как обычно, синхронизация случится при подключении.
- Если правил на двух устройствах, пока они были офлайн, побеждает более свежая
  версия — автоматически, без всплывающих вопросов.
- Перед тем как принять облачную версию, местная копия на секунду сохраняется
  в браузере под ключом `gamelife_state_backup` — на случай, если что-то пошло не так.

Ручной экспорт/импорт из раздела «Резервная копия» продолжает работать и остаётся
полезным как независимая страховка.

## Важно про данные

Данные хранятся в `localStorage` того браузера, где ты открываешь файл:

- Один и тот же браузер и путь к файлу — прогресс сохраняется.
- Очистка данных браузера, другой браузер или другой компьютер — прогресс будет пустым.

Поэтому раз в пару недель заходи в **Настройки → Резервная копия → Экспорт в файл**.
Приложение само напомнит, если бэкапа не было больше двух недель. Восстановление —
кнопкой «Импорт из файла».

## Настройка под себя

- **Настройки** — валюта, тёмная/светлая тема, 6 акцентных цветов, звук и конфетти.

## Структура проекта

```
index.html      разметка и подключение скриптов
style.css       всё оформление и адаптив
js/state.js     константы, состояние, хранилище, миграции
js/ui.js        тосты, модалки, конфетти, звук, графики на SVG
js/engine.js    журнал событий, стрики, крон, финансовые хелперы
js/main.js      навигация, запуск
js/views-*.js   по файлу на каждую вкладку
js/sync.js      синхронизация между устройствами через Supabase
js/food-db.js   встроенный офлайн-справочник КБЖУ на русском
supabase/       функция-посредник для распознавания еды по фото
SETUP-FOOD-AI.md  как её развернуть
manifest.json   описание приложения для установки на домашний экран
sw.js           service worker: работа без интернета
icons/          иконки приложения
start-for-phone.cmd   раздача по локальной сети для быстрой проверки
```
